# 2026-10-18 代码修改记录

> 记录本轮业务改造与缺陷修复的范围、原因与验证方式。相关背景见 [项目说明](./../PROJECT_CONTEXT.md)，
> 测试说明见 [测试说明](./../testing/README.md)。

## 1. 本轮目标

把最初用于演示的"通用对话 + 通用智能体"收敛为可交付的电商售后场景，并修复试运行中暴露的执行循环、
终止语义、工具安全与前端展示问题。

## 2. 主要改动

| 范围 | 改动 |
|---|---|
| 业务 | 提示词、知识库与前端文案改为电商售后口径（退换货 / 物流 / 商品质量 / 价保 / 发票） |
| 工具 | 移除终端执行、任意 URL 抓取、任意资源下载三个高危工具；新增规则检索、联网搜索、文件读写、PDF 生成、任务终止 |
| 智能体 | 修复工具调用参数、循环退出条件、终止语义与消息上下文；新增 `searchPolicy` 检索工具，政策类问题先检索再回答 |
| RAG | 文档按「主题 - 分类」命名并写入 `topic` 元数据；关键词增强后入库；客服提供 Advisor 与检索工具两条路径 |
| 前端 | 收敛为首页 + 工作台两页；移除步骤噪声，增加 `progress` 状态行与轻量 Markdown 渲染 |
| 测试 | 新增 20 个后端测试类（97 条用例）与 3 组前端测试（29 条），补充测试说明 |

## 3. 修复的缺陷

| 编号 | 级别 | 问题 | 修复 |
|---|---|---|---|
| BUG-01 | 高（安全） | 文件工具未校验路径，可用 `../` 读写 `tmp/file` 之外的文件（含本地密钥配置） | 新增 `ToolPathResolver`，规范化后必须位于基准目录内 |
| BUG-02 | 高（安全） | PDF 工具未校验文件名，可写入 `tmp/pdf` 之外 | 复用 `ToolPathResolver` |
| BUG-03 | 中（功能） | 联网搜索结果少于 5 条时整段失败 | 按实际数量截取；空结果与缺字段分别处理 |
| BUG-04 | 低（健壮性） | `generatePDF` 内容为 null 时抛未封装异常 | 入参校验并统一返回错误文案 |
| BUG-05 | 低（潜在安全） | 文件对话记忆的 `conversationId` 未校验，可路径穿越（组件默认未启用） | 会话 ID 规范化校验 |
| BUG-06 | 中低（设计） | `BaseAgent` 执行结束后状态不复位，同一实例第二次 `run` 抛异常 | 新增 `startNewRun()`，复位状态与步骤计数 |

此外修复了智能体执行循环与终止语义相关的 5 个问题（`.tools()` 用法、`ERROR` 状态未退出循环、
终止时答复丢失、第 8 步误报超限、工具结果污染界面），详见项目说明 §8。
