# 极简 2 页方案 · 设计示意

这是一版**静态示意图**，不是最终页面。目的是先确认页面数量、信息密度和字号尺度；确认后再改 Vue 前端。

## 页面结构

| 页面 | 路由建议 | 内容 |
| --- | --- | --- |
| 首页 | `/` | 一句说明、两个入口、规则索引、三步处理流程 |
| 工作台 | `/workspace?mode=chat` / `?mode=agent` | 客服与智能体共用一页，用顶部模式切换 |

- 总计 **2 个页面**，少于“3 页以内”的上限。
- 不再单独做 404 页面；未知路由直接回首页。
- 现有 `/aftersales`、`/agent` 建议重定向到 `/workspace?mode=chat|agent`，保留旧链接。

## 相比当前版本的取舍

**去掉**

- 180px / 416px 的展示级大字与整屏 CTA
- 大幅照片、全幅照片带、图片许可区块
- 珊瑚色 / 夜黑色的大章节色块
- 巨型页脚字与多列页脚
- 独立的 404 页面
- 客服页与智能体页各一套重复骨架

**保留**

- 纸色、墨色、单一绿色强调色
- 宋体标题 + 黑体正文的搭配
- 方形直角、平涂表面、无渐变、无静态阴影
- 规则索引、真实对话、流式状态
- 两套规则/工具边界说明

## 字号

| 层级 | 桌面 | 手机 |
| --- | --- | --- |
| 页面标题 | 40px | 28px |
| 区块标题 | 24px | 21px |
| 工作台标题 | 32px | 26px |
| 正文 | 15–16px | 13–14px |

没有超过 40px 的字；信息密度比上一版高，但保留了留白。
